# matrix-rain

A Bash script that displays a Matrix-style digital rain animation in the terminal.

This is my first Git project. The script was created with AI assistance.

## Usage

Run the following commands in a Linux terminal:

```bash
git clone https://github.com/Wangyc8557/matrix-rain.git
cd matrix-rain
bash screen_matrix.sh
```

Press **Esc** or **Ctrl+C** to exit.
